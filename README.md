# Rahila Rahad — Portfolio Website

A luxury, high-performance personal portfolio website for **Rahila Rahad** — AI Content Creator & 3D Visual Artist.

## Features
- **3D Canvas Motion Engine**: Hardware-accelerated 153-frame scroll animation.
- **Editorial About & Skills**: Vertical milestone timeline and editorial list.
- **Services Showcase**: Tailored AI Content Creation, AI Video Production, and Social Media Content with cursor floating thumbnail preview.
- **Interactive Projects Showcase**: Two-column header, category filter tabs (ALL, AI VIDEO, AI IMAGE, DIGITAL CONTENT), 3-column project grid with hover physics.
- **Dark Theme**: Deep black (`#0A0A0A`), warm bronze accents (`#A67C52`), and white serif typography.

## Tech Stack
- HTML5, CSS3, JavaScript (ES6+)
- Node.js (Static HTTP Server)
- GSAP & ScrollTrigger
- Lenis Smooth Scroll
